Approach
Seven features were used: Pclass, Sex, Age, SibSp, Parch, Fare, and Embarked. PassengerId was excluded since it has no predictive value. Name, Ticket, and Cabin were also excluded, as they would require additional feature engineering to be useful and it wasn't clear how much extra predictive information could be extracted from them.
Missing values in Age and Fare were initially imputed with the respective median and missing values in Embarked with the most common category. The categorical variables Sex and Embarked were then one-hot encoded. The results varied between the two evaluation sets: median imputation achieved higher accuracy on the local validation set, whereas the version without imputation performed better on the Kaggle test set.
A Random Forest classifier was used as the model. To find good hyperparameters, 10-fold stratified cross-validation was performed with GridSearchCV. Stratification keeps the ratio of survivors to non-survivors roughly consistent across folds.
The first grid search tested different values for the number of trees (n_estimators), maximum tree depth (max_depth), minimum samples required for a split (min_samples_split), minimum samples per leaf (min_samples_leaf), and the number of features considered at each split (max_features). The best combination reached a mean cross-validation accuracy of 83.50%, using 200 trees, no depth limit, a minimum of 10 samples per split, a minimum of 2 samples per leaf, and sqrt for max_features. Compared to the default Random Forest (80.5%), this was a solid improvement. Building on that, a second, more targeted grid search was run around these promising values. This slightly improved the mean cross-validation accuracy to 83.73%, with 150 trees, no maximum depth, a minimum of 15 samples per split, 2 samples per leaf, and again sqrt for max_features.
For the final Kaggle submission, missing values were left un-imputed, since this version scored higher on Kaggle. The model was trained using the hyperparameters from the second grid search. The resulting Kaggle score was 78.23%, which is noticeably lower than the local cross-validation accuracy of 83.73%. This suggests the model didn't generalize to the actual test data as well as hoped.
For future improvements, feature engineering would probably be more useful than  hyperparameter tuning. Right now the model only uses the features with minimal preprocessing. Additional features like family size, whether someone was traveling alone, or information extracted from the Name (Mr./Miss/Master…) or Ticket columns could be useful for the model.
